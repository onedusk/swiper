For 1099-K forms, the IRS requires filing if, in a calendar year, the gross amount of total reportable
payments exceeds $20,000 and there are more than 200 transactions. Filing requirements for some states
might differ from federal requirements.
We outline state filing requirements for 1099-K forms to help you identify which states you can file directly
in your Dashboard, which states require a state tax registration or withholding ID when filing, and which
states youʼre responsible for filing directly with.
If you have done backup withholding or state withholding, you might have additional reporting
requirements with states. We recommend that you consult a tax advisor.
