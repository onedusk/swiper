Controllers
Events Controller: Public event listings and details
Admin::EventsController: Event management for administrators
API Controllers: RESTful endpoints for programmatic access
Checkout Controller: Handles the ticket purchase process
Cart Controllers: Manages the shopping cart functionality

Usage Examples
Creating an Event
1. Log in to the admin dashboard
2. Navigate to Events → New Event
3. Fill in the event details (name, date, location, etc.)
4. Upload an event image (supports JPG, PNG, GIF, and SVG)
5. Set the ticket price and availability
6. Save the event

Purchasing Tickets
1. Browse events on the public homepage
2. Select an event to view details
3. Add tickets to your cart
4. Proceed to checkout
5. Enter customer and payment information
6. Confirm purchase and receive order confirmation

API Documentation
The platform includes a RESTful API for programmatic access to events, orders, and customer data.
Full OpenAPI documentation is available in docs/api/openapi.yaml .

API Endpoints
GET /api/events - List all events
GET /api/orders - List all orders
GET /api/customers - List all customers
