Prerequisites
This project requires:
Ruby 3.3.7 (preferably managed using rbenv)
PostgreSQL 17
Node.js & Yarn (for Tailwind CSS)

macOS Setup with Homebrew
brew install rbenv
brew install postgresql@17
brew install node
brew install yarn

Getting Started
Installation
1. Clone the repository
git clone https://github.com/yourusername/think-events.git
cd think-events

2. Install dependencies
bin/setup

3. Set up environment variables
Create a .env file in the project root with:
# Development environment variables
MAILER_SENDER=noreply@example.com
APP_HOST=localhost:4000
# Optional: Resend API integration
# RESEND_API_KEY=re_your_api_key_here
# USE_RESEND=true

4. Start the development server
