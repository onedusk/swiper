Think Events
An event management and ticketing platform built with Ruby on Rails 8.0.
Event Management Platform

Overview
Think Events is a event/course management and ticketing platform that allows organizations to
create, manage, and sell tickets for events. The platform includes both an administrative interface for
event organizers and a customer-facing portal for event discovery and ticket purchases.

Key Features
Event Management: Create, edit, and manage events with detailed information
Ticket Sales: Sell tickets with customizable pricing
Shopping Cart: Allow customers to purchase tickets for multiple events
Customer Management: Track customer information and order history
Admin Dashboard: Monitor event performance metrics
REST API: Programmatically access events, orders, and customer data
Email Notifications: Automated emails for order confirmations and event updates

Technology Stack
Framework: Ruby on Rails 8.0
Ruby Version: 3.3.7
Database: PostgreSQL
Frontend: Tailwind CSS
Authentication: Devise
File Storage: Active Storage with AWS S3 compatibility
Email Service: Resend
JavaScript: Stimulus
Hosting: Fly.io (recommended)
