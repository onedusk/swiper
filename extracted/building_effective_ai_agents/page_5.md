The prompt chaining workflow

When to use this workflow: This workflow is ideal for situations
where the task can be easily and cleanly decomposed into fixed
subtasks. The main goal is to trade off latency for higher accuracy, by
making each LLM call an easier task.
Examples where prompt chaining is useful:
Generating Marketing copy, then translating it into a different
language.
Writing an outline of a document, checking that the outline
meets certain criteria, then writing the document based on the
outline.

Workflow: Routing
Routing classifies an input and directs it to a specialized followup
task. This workflow allows for separation of concerns, and building
more specialized prompts. Without this workflow, optimizing for one
kind of input can hurt performance on other inputs.
